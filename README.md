# Anxious-Butterfly
Anxious Butterfly is a senior capstone project designed to help users manage anxiety. 
We created an early prototype with limited tools. The code in this repository won't function as it isn't linked to a database, 
but it allows users to view the source code and understand our approach to the project.

Disclaimer: 
The code in this repository will not run as it is not connected to a database. Additionally, the code is written in PHP, and will require proper server and database configuration to function correctly. 
This repository is provided for educational purposes to view the source code and understand the development process.
